# Bugs Haunter

Arcade web pixel-art protagonizado por Agustín, un desarrollador que debe eliminar bugs dentro del PC antes de que el sistema colapse.

## Ejecutar

Requiere Node.js 18 o superior.

```bash
npm start
```

Abre [http://localhost:3000](http://localhost:3000).

## Controles

- `WASD` o flechas: mover
- Ratón + clic: apuntar y disparar
- `Shift`: dash defensivo

Sobrevive 90 segundos, encadena eliminaciones para aumentar el combo y recoge parches verdes para recuperar integridad.
